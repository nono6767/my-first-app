# my-first-app

ピラティスインストラクター向けのレッスン提案アプリです。
お客様の体の特徴・悩みや、姿勢・身体評価（視診・触診の結果）を選ぶと、対応するおすすめのピラティスエクササイズを表示します。性別（任意）を選ぶと、骨格の傾向に合わせた項目・エクササイズも追加されます。

## 中身

- `index.html` … 画面の内容（性別・悩み・姿勢評価の選択フォームと結果表示エリア）
- `style.css` … 見た目（デザイン）
- `script.js` … 「悩み・姿勢タイプ → おすすめエクササイズ」の対応表と、選択に応じて結果を表示する処理

## 見てみる方法

`index.html` をブラウザで開くだけで確認できます。

## 内容を増やしたいとき

- `script.js` の `CONCERNS`（お悩み）、`POSTURE_ASSESSMENTS`（姿勢タイプ）の一覧に項目・エクササイズを追加・編集すれば、選択肢と提案内容を増やせます。
- 項目やエクササイズに `genders: ["male"]` または `genders: ["female"]` を付けると、その性別を選んだときだけ表示されます（付けなければ男女共通）。
- `ASYMMETRY_ITEMS` は「肩・骨盤の高さの左右差」専用の一覧です。高い側を選ぶと `tightMuscle`（使いすぎ傾向の筋肉）・`weakMuscle`（使えていない傾向の筋肉）と、`side: "high"/"low"/"both"` を付けたエクササイズが、対応する側の表示付きで出てきます。
