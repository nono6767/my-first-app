# my-first-app

ピラティスインストラクター向けのレッスン提案アプリです。
お客様の体の特徴・悩みを選ぶと、対応するおすすめのピラティスエクササイズを表示します。性別（任意）を選ぶと、骨格の傾向に合わせた項目・エクササイズも追加されます。

## 中身

- `index.html` … 画面の内容（性別・悩みの選択フォームと結果表示エリア）
- `style.css` … 見た目（デザイン）
- `script.js` … 「悩み → おすすめエクササイズ」の対応表と、選択に応じて結果を表示する処理

## 見てみる方法

`index.html` をブラウザで開くだけで確認できます。

## 悩み・エクササイズの内容を増やしたいとき

`script.js` の先頭にある `CONCERNS` という一覧に、悩みとエクササイズを追加・編集すれば、選択肢と提案内容を増やせます。
項目やエクササイズに `genders: ["male"]` または `genders: ["female"]` を付けると、その性別を選んだときだけ表示されます（付けなければ男女共通で表示されます）。
