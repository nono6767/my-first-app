# my-first-app

ピラティスインストラクター向けのレッスン提案アプリです。
お客様の体の特徴・悩み、姿勢・身体評価（視診・触診の結果、または横向き・後ろ向きの写真からのAI自動判定）、運動経歴を選ぶと、対応するおすすめのピラティスエクササイズを表示します。性別（任意）を選ぶと、骨格の傾向に合わせた項目・エクササイズも追加されます。姿勢・左右差の選択内容からは、考えられる生活習慣・クセの予測（例：「フラットバック × 右肩上がり」）も表示されます。最後に、選んだ項目の中で重なりの多いエクササイズを中心とした「レッスンまとめ」（上位5つ）も表示されます。

## 中身

- `index.html` … 画面の内容（性別・悩み・姿勢評価・運動経歴の選択フォームと結果表示エリア）
- `style.css` … 見た目（デザイン）
- `script.js` … 「悩み・姿勢タイプ・スポーツ歴 → おすすめエクササイズ」の対応表と、選択に応じて結果を表示する処理

## 見てみる方法

`index.html` をブラウザで開くだけで確認できます。

## 内容を増やしたいとき

- `script.js` の `CONCERNS`（お悩み）、`POSTURE_ASSESSMENTS`（姿勢タイプ）、`SPORTS`（運動経歴）の一覧に項目・エクササイズを追加・編集すれば、選択肢と提案内容を増やせます。
- 項目やエクササイズに `genders: ["male"]` または `genders: ["female"]` を付けると、その性別を選んだときだけ表示されます（付けなければ男女共通）。
- `ASYMMETRY_ITEMS` は「肩・骨盤の高さの左右差」専用の一覧です。高い側を選ぶと `tightMuscles`（使いすぎ傾向の筋肉）・`weakMuscles`（使えていない傾向の筋肉、複数指定可）と、`side: "high"/"low"/"both"` を付けたエクササイズが、対応する側の表示付きで出てきます。
- `SPORTS` のエクササイズに `tag: "クセ改善"` または `tag: "パフォーマンス"` を付けると、結果一覧にその表示が付きます。
- 「レッスンまとめ」は `buildSummary()` が、選んだ項目すべてのエクササイズ名を数えて、複数の項目に共通して出てくるものを優先的に上位（デフォルト5つ）に並べる仕組みです。件数を変えたい場合は `buildSummary(selectedItems, 5)` の `5` を書き換えてください。
- 「考えられる生活習慣・クセ（予測）」は `buildHabitSummary()` が、チェックされた `POSTURE_ASSESSMENTS` と選ばれた `ASYMMETRY_ITEMS`（左右差）それぞれの `habitHypothesis`（考えられる生活習慣・クセの文章）を集めて表示する仕組みです。見出しは各項目の `shortLabel`（左右差の場合は `ASYMMETRY_SHORT_LABEL` の該当する側のラベル、例「右肩上がり」）を「×」でつないで作ります（例：「フラットバック × 右肩上がり」）。`habitHypothesis` を持つ項目が1つもチェックされていない場合は、この欄自体が表示されません。新しい姿勢タイプ・左右差項目を追加するときは、`shortLabel` と `habitHypothesis` も一緒に追加すると、この予測欄に反映されます。
  - 運動経歴（`SPORTS`）も選ばれている場合は、見出しにスポーツ名も「×」で追加されます（例：「フラットバック × 右肩上がり × ゴルフ」）。さらに `SPORT_HABIT_INSIGHTS`（`POSTURE_ASSESSMENTS`/`ASYMMETRY_ITEMS` の `id` × `SPORTS` の `id` の組み合わせで、その姿勢の傾向がそのスポーツにどう影響しやすいか・パフォーマンス向上のポイントをまとめた一文）に該当する組み合わせがあれば、「スポーツでの影響とパフォーマンスアップのポイント」として選んだスポーツごとに追加表示されます。新しい姿勢タイプやスポーツを追加したときは、`SPORT_HABIT_INSIGHTS` にもその組み合わせの一文を追加すると、この欄に反映されます（追加していない組み合わせは単に表示されないだけで、エラーにはなりません）。
- 姿勢・身体評価の各項目には、横から見た人型シルエット図（`POSTURE_DIAGRAMS`）が付いています。実際の姿勢分析と同じように、基準の垂直線（plumb line）に対して耳・肩峰・骨盤（大転子）・膝・くるぶしの5点がどれだけ前後にずれるかで姿勢タイプを表現しています。図は `buildPostureDiagram()` という関数が `POSTURE_DIAGRAM_PARAMS` の数値から自動生成します。新しい姿勢タイプを追加する場合は、`POSTURE_DIAGRAM_PARAMS` に `POSTURE_ASSESSMENTS` の `id` と同じキーで以下のパラメータを追加してください（省略した値は 0 扱い）。
  - `earDx` / `shoulderDx` / `hipDx` / `kneeDx` / `ankleDx` … 基準線からの前後のずれ（+で前方、-で後方）
  - `backBulge` … 胸椎後弯（猫背）の強さ
  - `frontBulge` … 腰椎前弯（反り腰）の強さ（マイナスで平背方向）
  - `pelvisRotation` … 骨盤ブロックの回転角度（骨盤前傾・後傾用）

## 写真からの姿勢自動分析について

「姿勢・身体評価」の中に、横向きの写真を選ぶと自動で姿勢タイプにチェックが入る機能があります。

- ブラウザ内で動くAI（[MediaPipe Pose](https://ai.google.dev/edge/mediapipe/solutions/vision/pose_landmarker)）を使って耳・肩峰・骨盤・膝・くるぶしの位置を検出します。**写真は外部に送信されず、端末内で処理されます。**
- 写真の中で人物が小さい（遠い）と検出精度が落ちるため、2段階で検出します。まず写真全体でラフに検出し（`computeCropRect()`）、頭〜足がぴったり収まる範囲を割り出して、そこだけ切り抜いて拡大し（`buildZoomedCanvas()`、必要なら高さ800px相当まで拡大）、もう一度そこで検出し直します。この2回目の結果を最終的な検出・判定・写真表示に使います。
- 検出した5点を `buildPostureDiagram()` と同じ座標の考え方（基準線からのズレ）に変換し、2段階で判定します。
  1. **体幹の全体パターン**（カイホロードシス／フラットバック／スウェイバック／猫背の4つ、`POSTURE_BODY_TYPE_IDS`）から、一番近いもの1つだけを選ぶ（`matchBodyType()`）。ズレの大きさではなく「向き・パターン」の近さ（コサイン類似度）で比較しているため、図解用に大きめに設定してある基準値と、実際の写真の控えめなズレ量とのスケールの違いに影響されにくくなっています。ズレが小さすぎる（`BODY_TYPE_MIN_MAGNITUDE`未満）場合や、どのタイプとも向きが十分似ていない（`BODY_TYPE_MIN_SIMILARITY`未満）場合は何も選びません。
  2. **頭部・肩まわりの所見**（フォワードヘッド／巻き肩、`POSTURE_REGIONAL_FINDINGS`）は、体幹パターンとは別に、それぞれの目印となるズレが一定量（`threshold`）を超えたら独立してチェックします（`detectRegionalFindings()`）。体幹パターンと同時に成立してもよい仕組みです（例：カイホロードシス＋フォワードヘッド）。
- `BODY_TYPE_MIN_MAGNITUDE` / `BODY_TYPE_MIN_SIMILARITY` / 各所見の `threshold` は実際のデータに基づく厳密な校正値ではなく、最初の目安です。実際の写真で試した結果に応じて調整してください。
- 検出結果は写真の上に点と基準線で重ねて表示されます。点がずれていれば指（またはマウス）でドラッグして位置を調整でき、指を離すとその場で判定をやり直します。ドラッグ中は指で隠れないよう、点を実際の指の位置より少し上に浮かせて表示します（地図のピンと同じ考え方）。指の位置は点線と十字で示されます。浮かせる距離は `getDragLiftOffset()` で調整できます。
- AIモデル（`@mediapipe/tasks-vision`）はCDNから読み込むため、初回利用時にインターネット接続が必要です。オフラインの場合や読み込みに失敗した場合はエラーメッセージが表示されます。
- あくまで簡易的な目安です。写真の写り方（服装・光の当たり方・カメラの角度など）で精度が変わるため、実際の視診・触診と合わせて確認・修正してください。

## 写真からの左右差自動分析について

「姿勢・身体評価」の中に、後ろからの写真を選ぶと「肩の高さの左右差」「骨盤の高さの左右差」に自動でチェックが入る機能もあります。

- 後ろ姿（背中側）を選ぶ理由は、正面と違って鏡写しにならないため（後ろ姿は写真の左＝お客様の左）。左右の判定は `extractAsymmetryPoints()` と `splitByImageSide()` が写真上のX座標だけで決めており、MediaPipeの `left_shoulder`/`right_shoulder` といったラベル自体は信用していません（後ろ姿ではラベルの左右判定を誤ることがあるため）。
- 姿勢の自動分析と同じく、ラフに1回検出 → 頭〜足の範囲を切り抜いて拡大 → もう一度検出、という2段階です（`computeCropRect()` / `buildZoomedCanvas()` を共用）。
- 左右の高さの差は、体の高さ（耳〜くるぶしの平均）に対する比率で判定し、`ASYMMETRY_MIN_RATIO` 未満の差は「特に左右差なし」として、どちらも選びません。
- 検出した肩・骨盤の4点（`ASYM_POINT_KEYS`）は写真上にドラッグで調整でき、指を離すと `splitByImageSide()` で左右を判定し直すため、点を反対側まで動かしても正しく判定されます。
- 傾きが見やすいよう、両くるぶしの中間を通る縦の基準線（`centerX`）と、肩・骨盤それぞれの横線（2点の外側まで伸ばして表示、`extendLine()`）を写真に重ねて表示します。縦の基準線は自動計算だけだとズレることがあるため、線の上部にある持ち手（ハンドル）をドラッグして左右に調整できます（`CENTERLINE_KEY` / `getCenterLineHandlePos()`）。
